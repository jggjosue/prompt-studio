3D Innovation Garden — Project tour trails

A tour-led innovation garden designed around project videos, plot-by-plot storytelling, and zone transitions. A tour-led innovation garden experience highlighting project videos and movement through zones. An innovation garden in light mode with gravel paths, stylized vegetation, and themed plots by route (AI, Sustainability, Health). Each plot has a pedestal with a 3D video screen that plays project videos as textures. Routes can be followed with an auto tour that moves the camera and plays voiceover narration.

Each project includes video, technical sheet, and resource links. A curator system creates playlists of favorite projects and exports as PDF. Videos load on demand and play in HTML overlay with subtitles. Waypoint sharing via URL with camera fly-to. Analytics track route starts and project views. LOD for vegetation, prefers-reduced-motion, 2D fallback view.

**Deliverables:** index.html, styles.css, innovationGardenTours.js, assets/ (project videos, GLB models, SRT, transcripts).

**Stack:** Three.js, video HTML5, GSAP, IndexedDB, SpeechSynthesis.

**Interactions:** Auto tour by route with voiceover, video playback with 3D texture projection, project playlists, PDF export, shareable waypoints.
