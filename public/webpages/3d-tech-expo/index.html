3D Tech Expo with Video Demos and Interactive Stations

A tech expo where each station shows a technical demo and an explanatory video detailing architecture, APIs and use cases. The scene is a pavilion with thematic islands (AI, security, infra) and a 3D map for navigation. Selecting a station triggers a GSAP fly-to and the demo video plays on a 3D screen; alongside the video a panel shows highlighted code snippets (Prism.js) and a Try in Sandbox button (external link).

Demos include live 3D visualizations (data flows) synced with video via JSON cues. Deep dive mode pauses playback and allows inspecting logs and metrics in floating panels. Performance: heavy demos load on demand, Web Workers compatible. Accessibility: subtitles, transcripts, aria on snippets, prefers-reduced-motion. Metrics: demos started, snippets copied, time in deep dive. Sandbox integration and snippet security recommendations included.

**Deliverables:** index.html, styles.css, expo3d.js, assets/ (GLB station models, demo videos, JSON snippets).

**Stack:** Three.js, video HTML5, Prism.js, GSAP.

**Interactions:** Click station opens video + code snippet + sandbox button, 3D map navigation, deep dive mode with logs/metrics, live data visualization synced with video.
