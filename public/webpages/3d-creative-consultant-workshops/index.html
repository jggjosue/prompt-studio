3D Freelance Portfolio for Creative Consultant with Case Room and Workshop Videos

A 3D room where each table represents a workshop given by the creative consultant. Opening a table plays the workshop video with subtitles and attached materials (PDFs, slides). Includes a replay mode with scrubbing by sections (introduction, exercises, Q&A) and a synchronized notes panel that can be exported. Bookmark system by timestamp and auto summary generation (UI that prepares the package; actual generation can be delegated to backend).

Proxies for scrubbing, LOD for furniture. Accessibility: subtitles, transcripts, prefers-reduced-motion. Analytics: workshops viewed, bookmarks created.

**Deliverables:** index.html, styles.css, consultant3d.js, assets/ (workshop videos, models, PDFs).

**Stack:** Three.js, video HTML5, GSAP, LazySizes.

**Interactions:** Click table opens workshop panel with video + sections + notes + attachments bookmark at timestamp export notes generate summary package.
