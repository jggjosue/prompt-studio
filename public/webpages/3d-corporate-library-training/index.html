    3D Corporate Library — Docs and learning hub

    A docs-first learning hub optimized for references, clips, and discovery. A learning hub version of the corporate library optimized for docs, references, and discovery. A learning hub version of the corporate library focused on docs, clips, and discovery. A corporate library in light mode with shelves organized by department (IT, RH, Finances, Marketing). Each training clip has metadata and a panel that plays the video with subtitles and synchronized notes. Keyword search and filters by duration, department, and level. Selecting a result flies the camera to the shelf and plays the clip.

Personal note system linked to timestamps, saved in IndexedDB and exportable. Adaptive streaming, thumbnails and proxies for scrubbing. Accessibility: subtitles and full transcript per clip.

Performance: LOD and lazy-load per shelf. Metrics: completion rate, average time per clip, most frequent notes.

**Deliverables:** index.html, styles.css, corpLibrary3d.js, assets/ (training clips, metadata JSON, thumbnails, SRT, transcripts).

**Stack:** Three.js, video HTML5, GSAP, local search engine.

**Interactions:** Search and fly-to, timestamped notes, training playlists, scrubbing with proxies.
