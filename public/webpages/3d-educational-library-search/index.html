3D Light Mode Educational Library with Clips and Semantic Search

A 3D library in light mode with light-wood shelves containing educational clip volumes. Semantic search allows natural language queries; results illuminate relevant shelves and the camera flies to the clip. Each clip has rich metadata: title, duration, language, transcript, tags, difficulty. Selecting a clip plays it on a 3D panel and the transcript syncs with highlights that jump to timestamps.

Playlists by dragging clips to a 3D cart. 'Mark for review' adds personal notes with timestamps. Adaptive streaming, thumbnails and proxies for fast scrubbing. High-contrast mode and adjustable text size.

Scene optimized with LOD for shelves and lazy-load by section. Analytics tracks frequent searches, top clips, and navigation paths.

**Deliverables:** index.html, styles.css, library3d.js, assets/ (clips, metadata JSON, thumbnails, SRT, transcripts).

**Stack:** Three.js, video HTML5, GSAP, local embedding search.

**Interactions:** Semantic search illuminates shelves, fly-to clip, 3D playlists, scrubbing with proxies.
