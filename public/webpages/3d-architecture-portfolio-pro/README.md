## Prompt

```text
Crea una landing page web moderna para un estudio de arquitectura 3D.

Objetivo: transformar el diseño actual en una experiencia visual premium con arquitectura 3D, animaciones suaves y botones funcionales.

Requisitos principales:

* Mostrar la página dentro de un canvas 3D interactivo.
* Usar un estilo elegante, futurista y profesional para arquitectos 3D.
* Incluir una escena 3D con edificios, planos arquitectónicos, luces, sombras y profundidad.
* Crear una sección hero impactante con título, subtítulo y botones.
* Los botones deben funcionar correctamente:
    * “Ver proyectos” debe hacer scroll a la sección de portafolio.
    * “Contactar” debe hacer scroll o abrir la sección de contacto.
    * “Explorar en 3D” debe activar una animación o rotación de la escena.
* El diseño debe ser responsive para desktop, tablet y móvil.
* Agregar navegación superior con logo, Inicio, Servicios, Proyectos y Contacto.
* Incluir secciones: Hero, Servicios, Proyectos 3D, Proceso de trabajo, Testimonios y Contacto.
* Usar animaciones suaves al hacer scroll.
* Mejorar colores, tipografía, espaciado, sombras, tarjetas y botones.
* El sitio debe verse como una landing page real para vender servicios de arquitectura 3D.
* Trabaja libremente para mejorar la experiencia visual, la estructura y la interacción.

Estilo visual:
arquitectura 3D premium, glassmorphism, luces realistas, tonos oscuros elegantes, detalles dorados o azul eléctrico, edificios futuristas, renders arquitectónicos, diseño limpio, profesional, moderno e inmersivo.

Resultado esperado:
Una landing page completa, funcional, atractiva y lista para mostrarse en canvas, con botones interactivos, diseño 3D y experiencia profesional para arquitectos.
```
