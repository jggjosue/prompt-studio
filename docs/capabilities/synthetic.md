# Synthetic Data and Content

Esta es una capacidad central de Prompt Studio. La plataforma genera y administra imágenes, videos, texto, código, componentes y campañas coordinadas.

## Ciclo completo

`brief → Brand Kit → prompt versionado → generación → evaluación → aprobación → publicación`

## Evidencia

- Adaptadores para distintas familias de proveedores.
- Cola con créditos, progreso, reintentos y devolución ante fallo.
- Generación por lotes desde CSV.
- Contratos de salida y reparación determinista.
- Versionado y laboratorio A/B de prompts.
- Evaluación humana, regresión y selección automática de proveedor.
- Procedencia por activo: prompt, modelo, proyecto, licencia y publicaciones.
- Demo reproducible sin credenciales privadas.

## Riesgos controlados

- Claims potencialmente inventados se señalan antes de publicar.
- Los permisos de licencia nunca se presuponen.
- Los resultados privados no entran en observabilidad.
- Los fixtures de demo se etiquetan como sintéticos y no como benchmarks actuales.
