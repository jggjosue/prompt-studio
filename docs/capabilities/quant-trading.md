# Quant Trading

Esta capacidad **no está implementada** en Prompt Studio.

Stripe, créditos, costos, ingresos y margen pertenecen a la economía del producto; no constituyen trading cuantitativo. El repositorio no contiene estrategias, datos de mercado, ejecución de órdenes, backtesting ni gestión de riesgo financiero.

## Qué haría falta para sostenerla

- Dataset histórico con reglas de licencia y prevención de *look-ahead bias*.
- Backtester reproducible con costos y *slippage*.
- Separación de entrenamiento, validación y *out-of-sample*.
- Métricas de drawdown, Sharpe y exposición.
- Simulación o *paper trading* antes de cualquier ejecución real.

No se recomienda seleccionar esta categoría para la candidatura basándose en este proyecto.
