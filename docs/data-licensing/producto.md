# Producto y experiencia

## Problema

Los sistemas empresariales acumulan rastros valiosos de resolución de problemas: solicitud, contexto, decisión, acción, error, corrección y resultado. Exportarlos sin controles crea riesgos de privacidad, propiedad intelectual, confidencialidad y seguridad.

## Resultado para el cliente

El producto convertiría fuentes autorizadas en un paquete documentado y evaluable sin transferir la propiedad del original. Una licencia solo se consideraría cerrada cuando exista un acuerdo firmado y una entrega aceptada.

## Perfil de cliente

Puede participar una empresa de cualquier sector y tamaño si dispone de suficiente historial operativo autorizado. Son fuentes habituales los sistemas de comunicación, gestión de trabajo, conocimiento, CRM, finanzas y, cuando existe desarrollo de software, repositorios de código e integración continua.

La elegibilidad y los criterios de evaluación se detallan en [Perfil de empresa y fuentes](perfil-y-fuentes.md).

## Flujo propuesto

`conectar fuente → inventariar → confirmar derechos → excluir → anonimizar → evaluar → aprobar muestra → definir licencia → entregar → compensar`

### Estados

| Estado | Significado |
| --- | --- |
| Borrador | Las fuentes están descritas, pero no autorizadas para procesarse |
| En revisión | Se revisan derechos, contratos, sensibilidad y alcance |
| Preparación | Se genera una copia de trabajo aislada |
| QA bloqueado | Hay secretos, PII, licencia dudosa o calidad insuficiente |
| Aprobación | El propietario revisa muestra, métricas y términos |
| Disponible | Puede presentarse dentro del alcance aprobado |
| Licenciado | Existe acuerdo y destinatario identificable |
| Retirado | No se ofrecen nuevas licencias; se aplican obligaciones contractuales vigentes |

## Experiencia principal

El panel debería mostrar fuentes incluidas, categorías excluidas, volumen antes y después del saneado, riesgos abiertos, versión del dataset, compradores autorizados, licencias activas y compensación liquidada.

## Mensajes que no deben utilizarse

- “Venda todos sus datos”.
- “Anonimización garantizada”.
- “Ingresos asegurados”.
- “Compatible con cualquier regulación”.
- “Una vez anonimizado deja de existir riesgo”.

Son afirmaciones demasiado amplias y no verificables. La comunicación debe hablar de evaluación, controles, alcance contractual y pagos por acuerdos efectivamente cerrados.
